# User_Management_System
This project is a User Management System developed using the Laravel framework.It allows users to manage records efficiently by performing CRUD operations (Create, Read, Update, Delete) along with a search functionality.

🎯 2. Objective

The main objectives of this system are:
To implement CRUD operations using Laravel
To manage user data in a structured way
To allow searching of users by email
To handle file uploads (profile images)

🛠 3. Technologies Used
PHP (Laravel Framework)
MySQL Database
HTML & CSS
Blade Template Engine

⚙️ 4. System Features
➤ 4.1 Create (Add User)
User fills a registration form
Fields included:
Name
Email
CNIC
Telephone
Comments
Profile Picture
Data is stored in the database

All users are displayed in a table

Name

Comments
Profile Picture
➤ 4.3 Update (Edit User)
User can edit existing data
Form is pre-filled with old data
Updated data is saved in database
➤ 4.4 Delete (Remove User)
Each record has a delete button
Confirmation popup appears before deletion
Data is deleted after confirmation
➤ 4.5 Search Function
Users can search by email
Matching records are displayed
